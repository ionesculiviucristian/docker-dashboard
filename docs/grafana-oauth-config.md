# Grafana OIDC config (Authentik)

Grafana 13.0.1. Defaults from `[auth.generic_oauth]` (stable since Grafana 11.x+).

Single-user setup: every authenticated Authentik user becomes a Grafana **Admin** via `GF_USERS_AUTO_ASSIGN_ORG_ROLE`. No group-based role mapping.

| Env var | What it does | Default | Set to | Why |
|---|---|---|---|---|
| `GF_AUTH_GENERIC_OAUTH_ENABLED` | Master switch for generic OAuth/OIDC provider | `false` | `true` | Without it the provider is dormant. |
| `GF_AUTH_GENERIC_OAUTH_NAME` | Login button label ("Sign in with **X**") | `OAuth` | `Authentik` | Visible label on Grafana login page (only seen with `disableAutoLogin=true`). |
| `GF_AUTH_GENERIC_OAUTH_CLIENT_ID` | Client ID registered at the IdP | `""` | `grafana` | Must match the OAuth2 provider created in Authentik. |
| `GF_AUTH_GENERIC_OAUTH_CLIENT_SECRET` | Client secret from the IdP | `""` | secret from Authentik | Confidential client; populated after Authentik creates the OIDC provider. |
| `GF_AUTH_GENERIC_OAUTH_SCOPES` | Space-separated OAuth scopes requested from IdP | `user:email` | `openid profile email` | Default is GitHub-style and won't work for OIDC. Standard OIDC claims only — no custom scopes needed. |
| `GF_AUTH_GENERIC_OAUTH_AUTH_URL` | `/authorize` endpoint at IdP (browser redirect) | `""` | `https://authentik.../application/o/authorize/` | Browser-side flow — MUST be the public HTTPS URL (through Traefik). |
| `GF_AUTH_GENERIC_OAUTH_TOKEN_URL` | `/token` endpoint (code → tokens, server-to-server) | `""` | `http://authentik-server:9000/...` | Server-to-server inside Docker network — internal HTTP is fine, no Traefik, faster, no SSL dep. |
| `GF_AUTH_GENERIC_OAUTH_API_URL` | `/userinfo` endpoint (fetches user details with access token) | `""` | `http://authentik-server:9000/...` | Same — internal. |
| `GF_AUTH_GENERIC_OAUTH_SIGNOUT_REDIRECT_URL` | After Grafana logout, redirect to IdP's RP-Initiated Logout endpoint | `""` (logout only from Grafana) | `https://authentik.../application/o/grafana/end-session/` | Coordinated logout — kills session in Authentik too. Public URL (browser redirect). |
| `GF_AUTH_GENERIC_OAUTH_ALLOW_SIGN_UP` | Auto-create Grafana user on first OAuth login | `true` | `true` | Required for pure-SSO setup: first OIDC user gets provisioned automatically. |
| `GF_AUTH_GENERIC_OAUTH_AUTO_LOGIN` | Skip Grafana login screen, redirect straight to IdP | `false` | `true` | Pure SSO — no Grafana login screen, redirect to Authentik. |
| `GF_AUTH_DISABLE_LOGIN_FORM` | Hide the local username/password form | `false` | `true` | Closes the local-credential UI. Combined with random `GF_SECURITY_ADMIN_PASSWORD`, no UI path to local admin. |
| `GF_AUTH_GENERIC_OAUTH_EMAIL_ATTRIBUTE_NAME` | Claim name holding the email | `email:primary` | `email` | Default is legacy GitHub-style. OIDC standard claim is `email`. |
| `GF_AUTH_GENERIC_OAUTH_LOGIN_ATTRIBUTE_PATH` | JMESPath to Grafana username | `""` (falls back to email/sub) | `preferred_username` | Standard OIDC username claim. Without this, Grafana uses email as username. |
| `GF_AUTH_GENERIC_OAUTH_NAME_ATTRIBUTE_PATH` | JMESPath to display name | `""` | `name` | Standard OIDC name claim. |
| `GF_USERS_AUTO_ASSIGN_ORG_ROLE` | Default role for newly auto-created users | `Viewer` | `Admin` | Single-user stack — every authenticated user gets full access. No need for group-based role mapping or a custom scope. |

## Admin user / break-glass

- `GF_SECURITY_ADMIN_USER` is NOT set → defaults to `admin` (Grafana's hardcoded default).
- `GF_SECURITY_ADMIN_PASSWORD` is auto-generated by `services/grafana/deploy.py::pre_deploy` via `self.envs.generate(...)` — random, persisted to `.env`. Closes the `admin:admin` backdoor.
- `GF_AUTH_DISABLE_LOGIN_FORM=true` hides the local form from the UI.
- **Break-glass procedure** (Authentik unrecoverable): exec into the container and reset the admin password:
  ```bash
  docker compose exec grafana grafana-cli admin reset-admin-password <new-password>
  ```
  Then access via `https://grafana.../login?disableAutoLogin=true`. Note: `GF_AUTH_BASIC_ENABLED` is still `true` (default), so the admin can also be used programmatically via `Authorization: Basic ...` against `/api/*` — useful for emergency automation, risky if anyone learns the password.

## Login flow

1. Browser hits `https://grafana.../` → `AUTO_LOGIN=true` redirects immediately to Authentik `/authorize` with `scope=openid profile email`.
2. User authenticates at Authentik.
3. Authentik returns the ID token with standard OIDC claims (`sub`, `email`, `preferred_username`, `name`).
4. Grafana receives the token, extracts username/email/name via the JMESPath configs.
5. First-time login → user is auto-created with role `Admin` (from `GF_USERS_AUTO_ASSIGN_ORG_ROLE`).
